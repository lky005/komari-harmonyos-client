# LK监控

在手机上查看 [Komari](https://github.com/komari-monitor/komari) 服务器监控数据的应用，
用 ArkTS 编写，运行在 HarmonyOS 手机上。

Komari 是一个自托管的服务器监控方案（Go 后端 + Agent 上报 + Web 面板）。
这个应用把它的面板装进手机：不开电脑也能看每台机器跑得怎么样。

## 功能

- **节点列表**：每台机器的 CPU、内存、磁盘、实时网速、负载和在线状态，
  有 GPU 的机器也能看到 GPU 用量；支持按名称搜索
- **节点详情**：CPU、内存、磁盘、网速等指标的历史曲线，
  可切换 1 小时 / 6 小时 / 24 小时 / 7 天
- **Ping 监控**：任务列表、延迟曲线、丢包统计
- **多服务端**：可以添加多台 Komari 服务器，随时切换；
  支持账号密码或 API Key 登录，能记住密码，会话过期后自动重登
- **刷新设置**：轮询间隔、并发数、Ping 缓存时长都可以在设置里调整
- **深浅色**：跟随系统切换

隐私方面：只调用 Komari 的公开接口，不会对服务器做任何管理操作；
密码和会话保存在系统的加密存储里，不落明文。

两点限制：开启了「私有站点」的服务器必须登录才能看到节点；
开启了两步验证（2FA）的账号目前无法登录。

另外：多服务端的添加、切换等这些功能测试得还不充分，不保证完全没有问题，
用的时候遇到 bug 欢迎反馈。

## 系统要求

- HarmonyOS 手机，系统版本 6.1.1 或更高
- 一台部署好的 Komari 服务器（1.4.x）

## 安装使用

1. 从 Release 下载 HAP 包安装，或按下一节自己构建
2. 打开应用，填入 Komari 服务器地址
3. 需要的话登录（账号密码或 API Key）
4. 然后就能看到节点列表和 Ping 数据了

## 自己构建

1. 用 DevEco Studio 打开项目目录
2. 等待 `oh_modules` 同步完成
3. 配置签名：File → Project Structure → Signing Configs，勾选自动签名生成调试证书
4. 连接真机或启动模拟器，运行 `entry`

注意：HAP 包需要签名之后才能安装到真机，未签名的包安装会直接失败；
生成的调试签名供自己安装测试使用即可。需要支持 API 24 的 HarmonyOS SDK。
